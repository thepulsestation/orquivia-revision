From different drawing conventions to one shared standard for reading and sharing projects.

The gap to close

From interpreting each drawing differently to sharing a consistent reading.

01 / The starting point

The projects already existed. The shared standard did not.

Value Retail had drawings of existing projects produced in different ways. The documentation followed different graphic conventions and needed a standard drawing approach across projects.

02 / Why it mattered

Sharing a drawing means sharing a way to understand it.

The goal was a single way to view and share drawings with clients. When conventions change from one document to another, reading becomes inconsistent: before discussing the project, people need to understand how it has been represented.

03 / The consulting work

Analyse what exists. Find the common elements. Define a standard.

We started by analysing the available drawings. We identified recurring elements and conventions across projects and translated them into a shared representation framework. Standardisation was built from their own documentation.

04 / The resulting change

Different projects, one consistent reading.

The documentation was brought under a common standard for viewing and sharing drawings with clients. The result is a shared graphic approach across projects, rather than deciding representation conventions for each delivery.
